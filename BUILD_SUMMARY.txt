Evidence-Aware Brain Tumour Classification System
Explainable AI with Integrated Reliability Assessment

Academic Project | Bharati Vidyapeeth / SPPU | 2026-2027

================================================================================
WHAT WAS BUILT:
================================================================================

A complete end-to-end system for brain tumour classification that:
1. Classifies brain tumours using deep learning (CNN)
2. Generates visual explanations (Grad-CAM)
3. Evaluates explanation quality (Localization metrics)
4. Assesses explanation stability (Perturbation analysis)
5. Fuses evidence into reliability score
6. Outperforms confidence-only baseline

================================================================================
CORE COMPONENTS:
================================================================================

✓ Data Module (src/data/)
  - DatasetLoader: Patient-wise stratified splitting
  - Preprocessor: Image normalization, augmentation, transforms
  - BrainTumourDataset: PyTorch dataset with masks

✓ Model Module (src/models/)
  - TumourClassifier: ResNet50-based CNN
  - ModelTrainer: Training loop with early stopping
  - Checkpoint management

✓ Explainability Module (src/explainability/)
  - ExplanationGenerator: Grad-CAM implementation
  - GuidedBackprop: Alternative visualization method
  - Heatmap overlay & colormap generation

✓ Evaluation Module (src/evaluation/)
  - LocalizationEvaluator: IoU, Dice, Pointing Game, Energy Ratio
  - StabilityEvaluator: SSIM, Spearman correlation
  - Perturbation: Gaussian noise, blur, brightness, shift

✓ Reliability Module (src/reliability/)
  - ReliabilityAnalyzer: Evidence fusion algorithm
  - AUROC/AUPRC computation
  - Risk-coverage analysis
  - Baseline comparison

✓ Configuration (src/config.py)
  - Centralized settings for all modules
  - Model hyperparameters
  - Evaluation thresholds
  - Path management

================================================================================
EXECUTABLE SCRIPTS:
================================================================================

1. main.py
   - Complete training & evaluation pipeline
   - Usage: python main.py --mode [train|eval|both]
   - Trains classifier, evaluates reliability, computes AUROC/AUPRC

2. demo_single_prediction.py
   - Single image prediction with visualization
   - Usage: python demo_single_prediction.py --image X --mask Y --model Z
   - Generates comprehensive reliability report

3. setup.py
   - Package installation script
   - Usage: pip install -e .
